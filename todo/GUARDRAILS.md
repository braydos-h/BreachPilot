# What I would **not** add right now

This is important because BreachPilot already has enormous scope.

I would temporarily stop adding:

* more generic MCP tools;
* more swarm agents;
* more attack families;
* arbitrary new AI features;
* another model provider unless one is strategically important;
* fancy autonomous self-modification;
* cloud/team functionality;
* new persistence/memory mechanisms.

Until the project can answer:

> **How much better did this commit make autonomous penetration testing?**

with data.
